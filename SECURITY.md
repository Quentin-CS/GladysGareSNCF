# Politique de sécurité

## Signaler une vulnérabilité

Ne publiez pas les détails d’une vulnérabilité dans une issue publique. Utilisez l’onglet **Security** de GitHub et l’option de signalement privé du dépôt. Si cette option n’est pas disponible, ouvrez une issue demandant uniquement un canal privé, sans détail technique.

Indiquez la version de l’intégration et de Gladys, les étapes de reproduction et l’impact. Masquez les jetons, identifiants et données personnelles dans les journaux transmis.

Ne transmettez jamais votre jeton développeur SNCF dans une issue ou un journal. En cas d’exposition, révoquez-le depuis le portail SNCF puis remplacez-le dans la configuration de l’intégration.

## Versions prises en charge

La dernière version publiée reçoit les correctifs de sécurité. Mettez à jour l’intégration avant de signaler une vulnérabilité.

## Périmètre

Cette politique couvre ce dépôt et l’image Docker publiée par le projet. Les services SNCF et Gladys Assistant relèvent de leurs propres politiques de sécurité.
